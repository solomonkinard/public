# Security Policy

## Reporting a Vulnerability

* [Private vulnerability reporting](https://github.com/solomonkinard/public/security)

## What to Include

- Brief description and impact
- Steps to reproduce
- Affected version

## Timeline

- Acknowledgment: within 7 days
- Fix target: within 90 days
- Public disclosure: Whichever comes first of 90 days or until a fix ships

## Scope

Reports are welcome for:
- Code execution, privilege escalation, data exposure
- Supply chain and dependency issues

## Credit

* If you would like credit, please specify this in your report
* Credit will be provided in the changelog by default
